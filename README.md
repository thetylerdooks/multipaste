# Multipaste

**Everything you copied, one shortcut away.**

Windows has had a clipboard history for years: press Win+V and pick from the last things you copied. macOS still only remembers one item. Multipaste adds the missing piece. It is a small menu-bar app that keeps a history of what you copy and lets you paste any of it with **⇧⌘V**.

It is open source (MIT), runs entirely on your Mac, and contains no networking code.

Version 1.5.2 · macOS 13 Ventura or later · Apple silicon and Intel

## Features

- **Popout at your pointer.** Press ⇧⌘V and the history opens where your mouse is, always fully on screen.
- **Recent list, newest first**, with the source app and how long ago each item was copied.
- **Quick paste.** ⌘1 to ⌘9 paste the first nine items instantly.
- **Live search** across everything in your history.
- **Understands what you copied:**
  - plain text and rich text
  - links (shows the host)
  - colours (`#RGB`, `#RRGGBB`, `rgb()`), shown with a swatch
  - code, shown in a monospaced preview
  - images and screenshots, shown as thumbnails
  - files, shown with their name and icon
- **Emoji, Kaomoji and Symbols tabs** with built-in, searchable sets.
- **Skips secrets.** Items that password managers mark as concealed or transient are never recorded, and you can add any app to an ignore list (Keychain Access, 1Password and Bitwarden are ignored by default).
- **Limits you control:** maximum number of items, maximum age, maximum image size, plus Pause Recording and Clear History.
- **Starts at login by default**, so your history is always there. You can turn this off in Settings or from the menu-bar icon.
- **Configurable shortcut.**
- Lives in the menu bar. No Dock icon.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| ⇧⌘V | Open or close Multipaste (changeable in Settings) |
| Type | Search |
| ↑ / ↓ | Move the selection (← / → as well in the grid tabs) |
| Return | Paste the selected item |
| ⌘1 … ⌘9 | Paste that item straight away |
| Tab / ⇧Tab | Next / previous tab |
| ⌘, | Open Settings |
| Esc | Close |

You can also click an item to paste it, and clicking anywhere outside the popout closes it.

## Install

1. Download `Multipaste-1.5.2.dmg` from the [Releases](https://github.com/thetylerdooks/multipaste/releases/latest) page.
2. Open the DMG and drag **Multipaste** into **Applications**.
3. Launch it. New releases are signed with an Apple Developer ID and notarized by Apple, so they open normally.
   Version 1.5.1 and earlier were ad-hoc signed and not notarized, so macOS Gatekeeper blocks their first launch. For those versions, use any one of these:
   - Right-click (or Control-click) Multipaste in Applications and choose **Open**, then **Open** again.
   - Or try to open it once, then go to **System Settings > Privacy & Security**, scroll down and click **Open Anyway**.
   - Or run this in Terminal:
     ```sh
     xattr -dr com.apple.quarantine /Applications/Multipaste.app
     ```
4. A clipboard icon appears in the menu bar and the welcome window opens.
5. Multipaste starts automatically when you log in. You can turn this off in Settings or with **Launch at Login** in the menu-bar menu. macOS may show a "Login Item Added" notification the first time; if it asks for approval, allow Multipaste under **System Settings > General > Login Items**.

### Grant Accessibility access

Multipaste asks for Accessibility access for one reason: to press ⌘V for you in the app you were using, so the item you picked is pasted immediately. It never reads your screen or your keystrokes.

- Click **Allow Accessibility…** in the welcome window, or
- open **System Settings > Privacy & Security > Accessibility** and switch on **Multipaste**.

If you skip this, Multipaste still works: it puts the item on the clipboard and you press ⌘V yourself.

## Privacy

- **No network access.** There is no networking code anywhere in the app: no analytics, no telemetry, no crash reporting, no update checks. Link previews are derived from the URL text itself; nothing is ever fetched.
- **Your data stays on your Mac.** The history is stored in:
  ```
  ~/Library/Application Support/Multipaste/
  ├── history.json
  └── images/
  ```
- **Secrets are skipped.** Pasteboard items flagged `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType` or `com.agilebits.onepassword` are never recorded, and neither is anything copied while an app on your ignore list is frontmost.
- **Wiping everything.** Choose **Clear History…** from the menu-bar icon or Settings. To remove all traces, quit Multipaste and run:
  ```sh
  rm -rf ~/Library/Application\ Support/Multipaste
  defaults delete com.tylerdooks.multipaste
  ```

## Uninstall

Open **Settings** from the menu-bar icon, scroll to the bottom and click **Uninstall Multipaste…**. After you confirm, Multipaste deletes your clipboard history and its settings, turns off Launch at Login, moves itself to the Trash and quits. If it cannot move itself (for example when it is not in a folder you can write to), it still deletes the data and asks you to drag the app to the Trash yourself.

To uninstall by hand instead:

1. Turn off **Launch at Login** in the menu-bar menu, then quit Multipaste.
2. Drag Multipaste from Applications to the Trash.
3. Remove its data and settings:
   ```sh
   rm -rf ~/Library/Application\ Support/Multipaste
   defaults delete com.tylerdooks.multipaste
   ```

Either way, macOS keeps the Accessibility entry. Remove it under **System Settings > Privacy & Security > Accessibility**, or run `tccutil reset Accessibility com.tylerdooks.multipaste`.

## Build from source

You need a Mac with Xcode (or the Xcode Command Line Tools for a single-architecture build).

```sh
git clone https://github.com/thetylerdooks/multipaste.git
cd multipaste
bash Scripts/build_app.sh
```

The script builds a universal binary with Swift Package Manager, assembles `build/Multipaste.app`, ad-hoc signs it and creates `build/Multipaste-<version>.dmg` and `build/Multipaste-<version>.zip`. The version comes from the `VERSION` file.

You can pass `SIGN_IDENTITY="Developer ID Application: …"` to sign with your own certificate and the hardened runtime instead of ad-hoc.

There are no third-party dependencies. Every push to `main` and every pull request is built by GitHub Actions (`.github/workflows/build.yml`). Pushing a tag that starts with `v` runs `.github/workflows/release.yml`, which signs the app with a Developer ID certificate, has Apple notarize it and publishes a release with the DMG, ZIP and SHA-256 checksums attached. See [RELEASING.md](RELEASING.md).

## Known limitations

- **Accessibility may need re-granting once when you update from 1.5.1 or earlier.** macOS ties the permission to the app's signature. Those versions were ad-hoc signed, and an ad-hoc signature changes with every build. Developer ID signed releases keep the same identity across updates. If auto-paste stops working after you update, remove Multipaste from the Accessibility list in System Settings and add it again.
- Launch at Login works best when the app is in `/Applications`.
- Only the global shortcut and the menu-bar icon open Multipaste. There are no mouse or desktop click hooks.
- The history has no pinning or favourites.
- The key names shown for shortcuts assume a US keyboard layout.
